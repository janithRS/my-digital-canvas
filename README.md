# Janith Silva Portfolio

Personal portfolio site, deployed to [janithsilva.com](https://janithsilva.com) via GitHub Pages.

## Development

```sh
bun install
bun run dev
```

Other scripts: `bun run build`, `bun run preview`, `bun run lint`, `bun run format`.

## Built with

- Vite
- React
- TypeScript
- Tailwind CSS
